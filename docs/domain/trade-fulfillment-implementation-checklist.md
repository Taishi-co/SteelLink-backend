# 交易履约改造清单

## 范围说明

本轮改造不包含 AI 采购实现。AI 采购由同事独立推进，本项目只保证主商城商品、仓储/物流/金融资源和订单闭环数据可以被 AI 采购后续引用。

状态说明：

- `[x]` 已完成并可用。
- `[~]` 部分完成，或后端已完成但前端/管理端/测试未接齐。
- `[!]` 已发现实现风险或 bug，需要修复。
- `[ ]` 未完成。

本轮主线：

1. 打牢 5 个平台服务基础资源。
2. 打通主商城商品上架和审核。
3. 迭代交易订单闭环。
4. 最后增强托盘融资和货权质押。

## 阶段 4：托盘融资与货权质押

- [x] 后端：买方选择托盘支付。
  - 已按产品流程支持买方选择已审核金融服务产品作为资金方，并创建账期/融资申请。
- [x] 后端：订单关联资金方金融服务产品。
- [x] 后端：生成融资申请。
- [x] 后端：资金方回传风控结果、授信金额、账期、费率。

  - 风控拒绝/额度不足：融资申请标记 `risk_rejected`，订单终止为已取消并释放锁定库存。
- [x] 后端：买方确认金额和定价。
- [x] 后端：生成债务合同。
- [x] 后端：买方签署并支付手续费。
- [x] 后端：资金方支付平台分佣并放款给卖方。
  - 放款接口已要求记录分佣金额、分佣凭证和定向放款凭证。
- [x] 后端：记录货权质押凭证。
  - 托盘垫资订单放款后必须先记录货权质押，才能发起物流竞价。
- [x] 后端：记录货权释放条件和释放事件。
- [x] 后端：资金方工作台可查询本企业融资申请并查看关联订单事件。
  - 新增 `GET /api/v1/orders/financing-requests/mine`。
  - 资金方可查看本企业参与的融资订单详情和事件链路。
- [x] 前端：托盘融资与货权质押页面和接口接入。
