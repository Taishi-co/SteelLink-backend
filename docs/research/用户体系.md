# 账号存储格式
有唯一ID，平台ID，个人N代码，企业T代码，角色，手机号，QQ号，邮箱

# 注册/登录

## 注册/登录方式
分为两种，手机号登录和账户（邮箱）登录
后续可考虑添加二维码登录/单点登录

问题1:**未注册用户是否考虑，自动创建注册**

注册时，创建密码，设置-必须要求小写+大写+数字

问题2:密码丢失如何找回？

之后到创建公司页面，选择是否创建，不创建就是个人用户

- 手机号登录

需要获取验证码，拿到验证码后登录成功
获取验证码时，要有滑块验证

- 账号邮箱登录

# 创建公司
需要进行实名认证
## 供应链角色（单选）
- 终端/次终端
- 钢贸商
- 物流公司
- 加工中心
- 钢厂
- 其他

## 平台角色（可多选）
- 采购

  需要验证：
  
  1.工商信息（公司名称，统一信用代码） 
  
  2.开票信息 
  
  3.授权委托验证
- 销售

  需要验证：
  
  1.工商信息（公司名称，统一信用代码） 
  
  2.法定代表人（身份证）

  3.收款账号
  
  4.授权委托验证

如果选择我有开通欧冶商城/商家直营买卖货的意向，需要授权委托验证中，添加（个人实名认证通过/
个人运营商三要素校验通过/
法人运营商三要素校验通过/
企业四要素校验通过）
