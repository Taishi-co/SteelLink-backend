# 测试用例

## TC-01 卖家发起物流竞价后查看竞价列表
- 前置：订单状态为已支付(4)
- 步骤：卖家发起物流竞价 → 切换到物流竞价Tab
- 预期：能看到竞价状态、报价数量、各物流方报价详情

## TC-02 卖家选择报价
- 前置：物流竞价中有至少1个报价
- 步骤：卖家点击"选择报价"→ 选择一个报价 → 确认
- 预期：订单状态变为待确认物流(16)

## TC-03 卖家关闭竞价
- 前置：订单处于物流竞价中(15)
- 步骤：卖家点击"关闭竞价"
- 预期：竞价关闭，订单状态回退

## TC-04 物流确认接单后信息自动填充
- 前置：卖家已选择报价，订单为待确认物流(16)
- 步骤：物流方点击"确认接单"
- 预期：
  - 订单状态变为运输中(17)
  - delivery_info 自动填充司机/车辆/地址/提货码
  - ShipmentTask 创建，status=pending_pickup
  - 买卖家收到通知

## TC-05 物流确认提货
- 前置：订单为运输中(17)，shipment_task=pending_pickup
- 步骤：物流方上传提货凭证 → 确认提货
- 预期：
  - shipment_task → picked_up
  - 买卖家收到"物流已提货"通知
  - 买卖家端进度条更新

## TC-06 物流确认送达
- 前置：shipment_task=picked_up
- 步骤：物流方上传送达凭证 → 确认送达
- 预期：
  - shipment_task → delivered
  - 订单状态 → 已送达(7)
  - 买卖家收到"物流已送达"通知

## TC-07 买家确认收货
- 前置：订单为已送达(7)或运输中(17)
- 步骤：买家点击"确认收货"
- 预期：订单状态 → 已收货(18)

## TC-08 卖家对账确认
- 前置：订单为已收货(18)
- 步骤：卖家点击"对账确认"
- 预期：订单状态 → 已对账(19)

## TC-09 物流上传签收凭证
- 前置：shipment_task=delivered
- 步骤：物流方上传签收凭证
- 预期：
  - shipment_task → signed
  - 买卖家收到"签收凭证已上传"通知
  - 订单状态不变（不跳过买家确认收货）
