# SL-BE-WAREHOUSE-ORDER-DETAIL

## 背景

仓储方订单列表可以通过 `GET /orders?role=warehouse` 查询当前企业参与的订单，但点击详情时需要调用 `GET /orders/:id`。当前详情权限只放行买方、卖方和资金方，未放行订单绑定的仓储企业，导致仓储方无法查看详情。

## 范围

- 调整订单详情读权限，允许 `delivery_info.warehouse_enterprise_id` 匹配当前企业时查看订单详情。
- 保持管理端、买方、卖方、资金方原有权限不变。

## 非范围

- 不新增订单写操作。
- 不调整订单列表过滤逻辑。
- 不改变订单事件接口，事件接口已支持仓储方读取。

## 验收标准

1. 仓储方能查看自己绑定仓储企业的订单详情。
2. 非订单参与方仍返回无权查看。
3. 买方、卖方、资金方、管理端现有详情读取不回退。
