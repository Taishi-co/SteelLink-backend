# SL-BE-AI-PROCUREMENT Test Cases

## API

- 未登录访问 AI 采购接口应返回鉴权错误。
- `POST /ai-procurements/parse` 输入 `帮我采购100套工业轴承，用于设备维修，需要申请订单融资`，应返回商品名称、数量、用途、融资意图和五阶段状态。
- 创建 AI 采购单后，我的列表应能看到该记录。
- 非创建人或非所属企业不应查看详情。
- 匹配结果为空时，提交审核应返回业务错误。
- 提交审核成功后，状态应变为 `review_submitted`。

## 回归

- 商品、订单、供求信息已有路由不应受影响。
- 数据库迁移应可在空库和已有库上重复执行。
